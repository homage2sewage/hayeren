# Cases by questions — the comprehensive table

status: draft (structural + editorial critic pass applied 2026-07-22)
date: 2026-07-22

## Purpose

The school method teaches each Armenian case with two questions
(animate/inanimate): ո՞վ/ի՞նչ, ո՞ւմ/ինչի՞, ումի՞ց/ինչի՞ց… That set
identifies the *form* but hides most of the *usage*: five different
cases can answer ե՞րբ "when?", five can answer a "where?"-type
question, and one form ո՞ւմ covers five distinct functions. This
file mines Dum-Tragut's scattered case-function descriptions
(morphology §2.1.3, pp. 97–120, plus the syntax chapters) into one
place and layers the question-word axis on top.

Reading conventions: backtick-quoted Armenian = verbatim corpus
bytes, page-cited (source typos preserved, marked *(sic — read …)*
with the corrected form); question words *not* in backticks and
marked *(prior)* are constructed here, not attested; † = obsolete /
marginal / literary-only function. Mining method and citation-audit
details: see Appendix.

## The school question table (sakayan p102)

| Case | person | non-person |
|---|---|---|
| Nominative | `ո՞վ` who? | `ի՞նչ(ը)` what? |
| Accusative | `ո՞ւմ` whom? | `ի՞նչ(ը)` what? |
| Genitive | `ո՞ւմ` whose? | `ինչի՞` whose? of what? |
| Dative | `ո՞ւմ` to whom? | `ինչի՞(ն)` to/for what? |
| Ablative | `ումի՞ց` from whom? | `ինչի՞ց` from what? |
| Instrumental | — | `ինչո՞վ` with what? |
| Locative | — | `ինչո՞ւմ` in what? |

The forms behind the questions (same page, sakayan p102; plural
inserts -ներ-):

| Case | animate (pupil) | inanimate (school) |
|---|---|---|
| NOM | `աշակերտ(ը)` | `դպրոց(ը)` |
| ACC | `աշակերտին` | `դպրոց(ը)` |
| GEN | `աշակերտի` | `դպրոցի` |
| DAT | `աշակերտի(ն)` | `դպրոցի(ն)` |
| ABL | `աշակերտից` | `դպրոցից` |
| INSTR | `աշակերտով` | `դպրոցով` |
| LOC | — | `դպրոցում` |

Why "accusative = ո՞ւմ" looks odd: morphologically Modern Eastern
Armenian (MEA) has five case forms — nominative, dative, ablative,
instrumental, locative. "Genitive" is the dative minus the article,
and the "accusative" is nominative for −human objects but *dative*
for +human objects (the book's foreword summarizes this as "human
definite referents", dumtragut p14, but the body's own rule is
humanness-driven: even an indefinite +human object takes dative
without article — `Նա ուսանողի սիրեց` "He loved a student." (dumtragut p78).
The tables below follow the school's seven
function-groups but cite Dum-Tragut's five-case analysis.

Extensions the school table omits:

- Adverbial interrogatives: `ինչպե՞ս` how?, `ինչո՞ւ` why?, `ե՞րբ` when?, `ո՞ւր` where (to)?, `որտե՞ղ` where?, `ինչքա՞ն`/`որքա՞ն`/`քանի՞` how much? (sakayan p379)
- The interrogatives themselves decline: instr. `ո՞ւմով` "кем?" (parnasyan p120) — so the instrumental "—" cell for persons is a *norm* gap, the form exists. The locative "—" is a real *paradigm* gap: ո՞վ has no locative form; "в ком?" is rendered `ո՞ւմ մեջ`, "о ком?" `ո՞ւմ մասին` (parnasyan p121).
- Case-specific adverbial questions attested in Dum-Tragut:
  - place: `որտե՞ղ` static (locative), `ո՞ւր` direction (nominative), `որտեղի՞ց` "where from?" (ablative), path `որի՞ վրայով` / `որի՞ մոտով` (instrumental) — all dumtragut p400
  - `ո՞ւր` vs `որտե՞ղ` register note: in written MEA `ո՞ւր` asks *only* for direction; colloquial MEA uses it for static place too (dumtragut p170)
  - time: `ե՞րբ`, `ինչքա՞ն ժամանակ`, `քանի՞ ժամով`, `երբվանի՞ց`, `մինչև ե՞րբ` (dumtragut p402); duration maps to the instrumental (dumtragut p403)
  - cause: `ինչո՞ւ` / `ինչի՞ց` / `ի՞նչ պատճառով` for the causal ablative (dumtragut p405)
  - "where (to)?" for the local nominative (dumtragut p99)

## One question, many cases

The pedagogical payoff of going beyond the 2-question set: the same
question is answered by different cases with different nuance.

**ե՞րբ / how long? (time)** — five cases, six patterns:

| Case | Nuance | Example |
|---|---|---|
| NOM temporal | time of action, no bounds | `Գիշերը անձրև եկավ` "The rain fell in the night." (dumtragut p99) |
| DAT temporal | time/date, article obligatory | `Գառնանը գնալու ենք Մոսկվա` *(sic — read Գարնանը)* "In spring we will go to Moscow." (dumtragut p103) |
| ABL temporal "since" | from a starting point (`երբվանի՞ց`, dumtragut p402) | `Առավոտվանից ձյուն է գալիս` "It has been snowing since morning." (dumtragut p114) |
| ABL temporal "in X" | future point after an interval | `Երեք շաբաթից նա մեկնում է Հավայան կղզիներ՝ արձակուրդի` "In three weeks he leaves for Hawaii for holiday." (dumtragut p92) |
| INSTR temporal | duration / vague point (`ինչքա՞ն ժամանակ`, dumtragut p402) | `Օրերով մառախուղը չոքում է մեր լեռներում` "The fog has been lingering in our mountains for days." (dumtragut p108) |
| LOC temporal | period within which completed | `Մեկ ժամում անցանք քսան կիլոմետր` "In one hour we covered 20 kilometres." (dumtragut p119) |

**where? (place)** — five cases:

| Case | Question | Nuance | Example |
|---|---|---|---|
| LOC | `որտե՞ղ` (dumtragut p400) | in(side) a place | `Արամը պարապում է լսարանում` "Aram studies in the auditorium." (dumtragut p118) |
| NOM local | `ո՞ւր` (dumtragut p400) | direction, motion verbs | `Գյուղանիցները գնացին դաշտ` *(sic — read Գյուղացիները)* "The farmers went to the field." (dumtragut p99) |
| DAT local | որտե՞ղ *(prior)* | at/on, position non-specific | `Նրանք պառկած էին գետի ափին` "They were resting on the river's bank." (dumtragut p104) |
| ABL local | `որտեղի՞ց` (dumtragut p400) | from / through | `Փողոցից կարելի է տեսնել բակն` "It is possible to see the courtyard from the street." (dumtragut p114) |
| INSTR local | `որի՞ վրայով`, `որի՞ մոտով` (dumtragut p400) | path via, motion verbs | `Գետո՞վ անցնել, թե կամուրջով գնալ` "(Shall we) pass the river or go over the bridge?" (dumtragut p108) |

**ո՞ւմ — one form, five functions** (the biggest trap for a Russian
speaker: кого/чей/кому are three different words, ո՞ւմ is one):

| Function | Russian question | Example |
|---|---|---|
| +human direct object | кого? | `Աշոտը տեսավ Արամին` "Ašot saw Aram." (dumtragut p103) |
| possessor (genitive) | чей? чья? | `Աշակերտի գիրքը նոր է` "The pupil's book is new." (dumtragut p100) |
| indirect object | кому? | `Դասախոսը ուանողին տվեց գիրքը` *(sic — read ուսանողին)* "The lecturer gave the book to the student." (dumtragut p103) |
| addressee of speech verbs | кому? | `Մայրը իր երեխաներին պատմում է հեքիաթ` "The mother tells the children a fairytale." (dumtragut p106) |
| owner with պատկանել "belong" | кому? | `Ալեքսանդրին պատկանել է բնակարանի` (երեք քառորդը) "Three-quarters of the apartment belonged to Alek'sandr…" (dumtragut p107) |

**ինչի՞ց — one form, five functions**:

| Function | Russian question | Example |
|---|---|---|
| origin/source | от кого/чего? | `Անուշը իր մորից նվեր ստացավ` "Anuš received a present from her mother." (dumtragut p111) |
| cause | от чего? почему? | `Նա այդ գիշեր ուրախությունից չքնեց` "That night he did not sleep for joy." (dumtragut p403) |
| material | из чего? | `Նա բրդից շորը չի սիրում` "He doesn't like the woollen cloth." (dumtragut p115) |
| fear/emotion verbs | чего? (бояться чего) | `Նա չի դժգոհում իր բնակարանի պայմաններից` "He is not dissatisfied with the conditions of his apartment." (dumtragut p117) |
| standard of comparison | кого/чего? (выше кого) | `Անին իր քրոջից գեղեցիկ է` "Ani is more beautiful than her sister." (dumtragut p113) |

## Nominative — ուղղական

| Function | Question | Example | Notes |
|---|---|---|---|
| Subject | `ո՞վ`/`ի՞նչ(ը)` (sakayan p102) | `Աշակերտը գնում է դպրոց` "The pupil goes to school." (dumtragut p97) | agent, natural force, experiencer all unmarked; `Քամին կոտրեց պատուհանը` "The wind broke the window" (dumtragut p98) |
| −human direct object | `ի՞նչ(ը)` (sakayan p102) | `Արամը կարդում է այս գիրքը` "Aram reads this book." (dumtragut p98) | extends to +human read as indefinite/non-specific: `Արամը բժիշկ կանչեց` "Aram called a doctor." (dumtragut p98) |
| Predicative | ո՞վ է / ի՞նչ է *(prior)* | `Նրա անունը Արամն է` "His name is Aram." (dumtragut p98) | NB for Russian speakers: no instrumental here (он был врачом → NOM: `Առաջին ձիավորը հնագետ էր` "The first horseman was an archaeologist.", dumtragut p98) |
| Vocative | — | `Վահա՜ն, արի՛ այստեղ` "Vahan, come here!" (dumtragut p98) | |
| Temporal | ե՞րբ *(prior)* | `Գիշերը անձրև եկավ` (dumtragut p99) | with `մինչև` = temporal end (dumtragut p99) |
| Local ("whither") | `ո՞ւր` (dumtragut p400); "where (to)?" (dumtragut p99) | `Գյուղանիցները գնացին դաշտ` *(sic — read Գյուղացիները)* (dumtragut p99) | with motion verbs; cf. `topics/morphology/accusative_for_locative.md` |
| Quantitative | ինչքա՞ն *(prior)* | `Մեկ ժամում անցանք քսան կիլոմետր` (dumtragut p99) | measuring units (`քսան կիլոմետր` is the NOM part) (dumtragut p99) |
| Price/value | ի՞նչ արժե *(prior)* | `Գիրքն արժե 1500 դրամ` "The book costs 1,500 Dram." (dumtragut p99) | |
| † Final (goal) | — | `Ոչխարը բե՛ր կթել` "Bring the sheep to milk!" (dumtragut p99) | obsolete, high-literary; now final dative `կթելու`, or colloquially `կթելու համար` (dumtragut p100) |
| Adposition government | — | `Մեքենան գնում է դեպի հրապարակ` "The car goes towards (the) square." (dumtragut p313) | դեպի, մինչև, նախքան, իբրև/որպես; postp. առաջ/հետո/անց with temporal expressions only (dumtragut p313) |
| Causer (causatives) | `ո՞վ` (sakayan p102) | `Արան Արամին դուռը բանալ է տալիս` "Ara makes Aram open the door." (dumtragut p345) | causer NOM, causee DAT |
| Standard of `քան`-comparison | — | `Արարատը ավելի բարձր է քան Արագածը` "Ararat is higher than Aragac." (dumtragut p549) | the other construction marks the standard with the ablative; "no difference in meaning" (dumtragut p549) |
| Equative comparee/standard | — | `Քույրս այնպես գեղեցիք է ինչպես դու` *(sic — read գեղեցիկ)* "My sister is as beautiful as you." (dumtragut p555) | |

## Genitive functions — սեռական (form = dative minus article)

All answer `ո՞ւմ` whose? / `ինչի՞` (sakayan p102); adnominal,
strictly preposed to the head noun (dumtragut p602).

| Function | Example | Notes |
|---|---|---|
| Possessive | `Աշակերտի գիրքը նոր է` "The pupil's book is new." (dumtragut p100) | no alienable/inalienable distinction (dumtragut p100) |
| Origin | `կատվի ձագը` "cat's young = 'kitten'" (dumtragut p100) | |
| Partitive | `ուսանուների մի խումբ` *(sic — read ուսանողների)* "A group of students" (dumtragut p101) | |
| Qualitative | `որսի շուն` "hound" (lit. hunting-dog) (dumtragut p101) | |
| Subjective | `ամպի գոռալը` "The rumbling of the cloud" (dumtragut p101) | head noun names the action |
| Objective | `շենքի կառուցումը` "The construction of the building." (dumtragut p101) | with nominalised-infinitive heads: dative only if +human (dumtragut p101) |
| Purpose/contents | `գրքերի պահարան` "Book shelf/bookcase" (dumtragut p102) | |
| † Price/value | `հինգ դրամի ապրանք` "Goods for five drams" (dumtragut p102) | fossilised, unproductive (dumtragut p102) |
| Possessor relative | `որի` + clause (dumtragut p511) | subordinator in dative, never takes the article (dumtragut p511) |

## Dative — տրական

| Function | Question | Example | Notes |

| Verbs of participation/connection | ինչի՞ն *(prior; form: sakayan p102)* | `Գիտաժողովին մասնակցելու են` (dumtragut p105) | մասնակցել, աջակցել, համաձայնել, ծանոթանալ |

| Adposition government | — | `Երեխան սեղանի տակից մոտեցավ մորը` "The child approached the mother from under the table." (dumtragut p323) | ~40 postpositions take DAT of nouns, GEN of 3rd-person pronouns (dumtragut p314); 1st/2nd person pronouns DAT: ինձ մոտ, քեզ համար (dumtragut p316) |

## Instrumental — գործիական

| Function | Question | Example | Notes |
|---|---|---|---|
| Instrument | `ինչո՞վ` (sakayan p102) | `Աշակերտը գրում է մատիտով` "The pupil writes with a pencil." (dumtragut p107) | prototypical |

## Locative — ներգոյական

"The locative is the only case that has only semantic functions."
(dumtragut p117)

| Function | Question | Example | Notes |
|---|---|---|---|
| Place (in/inside) | `որտե՞ղ` (dumtragut p400); `ինչո՞ւմ` (sakayan p102) | `Արամը պարապում է լսարանում` (dumtragut p118) | strictly "inside"; other positions need postposition + DAT (dumtragut p118) |
| Temporal (within a period) | ինչքա՞ն ժամանակում *(prior)* | `Մեկ ժամում անցանք քսան կիլոմետր` (dumtragut p119) | the "seldom used" caveat is about the վա-declension time-noun class, where only `շաբաթ` is productive: `մեկ շաբաթում` (dumtragut p92) |
| † Limiting complement | — | `Գործ կատարելում նա առողջ է և ժիր` (dumtragut p119) | book's own translation is garbled ("In fulfilling (his) the work he is wealthy and smart") — read: "in doing the work he is *healthy* (առողջ) and *lively* (ժիր)"; obsolete, replaced by `մեջ` phrase (dumtragut p119) |

Restrictions and doublets (the LOC is the most constrained case;
unlike Russian universal в + предложный):

- +human nouns and personal names take no locative outside literary style (dumtragut p117).
- Synthetic vs analytic doublet, LOC written/scientific vs `մեջ` colloquial: `Հայերենում օգտագրոծում են հինգ հոլով` *(sic — read օգտագործում)* (dumtragut p118) ≈ `Հայերենի մեջ օգտագործում են հինգ հոլով` "Five cases are used in Armenian." (dumtragut p118)
- Containment-between blocks LOC entirely: `Մատիտը գրքի մեջ է` "The pencil is in the book" (dumtragut p118), not `*Մատիտը գրքում է` (dumtragut p119) — the real locative would mean "in the contents of the book" (dumtragut p119).
- Colloquial bare-nominative replacement with place names + copula: `Արամը Երևան է` "Aram is in Yerevan." (dumtragut p119) — see `topics/morphology/accusative_for_locative.md`.
- Western Armenian has no locative at all (dumtragut p118).

## Russian-speaker traps

Constructed contrastive notes *(prior except where cited)*:

- **Predicate: no творительный.** Он был врачом → nominative
  (`Առաջին ձիավորը հնագետ էր`, dumtragut p98). The instrumental
  never marks the predicate noun.
- **бояться/избегать чего (род.) → ablative**, not genitive:
  `Ինչի՞ց ես վախենում` (parnasyan p124).
- **в + предложный is NOT universal**: the locative is blocked for
  +human nouns and non-"inside" relations (see Locative
  restrictions above); Armenian reaches for մեջ/վրա + DAT where
  Russian has a bare в/на.
- **с + творительный "together with"**: Armenian has both the bare
  instrumental (ընտանիքներով "with their families") and հետ + DAT;
  the bare instrumental is the more written variant (dumtragut p110).
- **кого?/чей?/кому? are all ո՞ւմ** — see the "one form, five
  functions" table above.

## Self-test (constructed, answers from the tables above)

1. "I'll be ready *in one minute*" — which case for "minute"? → ABL
   temporal-future (dumtragut p92).
2. "He was a doctor" — which case for "doctor"? → NOM predicative
   (никакого творительного).
3. "The window was broken *by the wind*" — which case? → ABL
   (natural force), not INSTR.
4. "The fire was put out *with water*" — which case? → INSTR
   (instrument).
5. "I'm afraid *of dogs*" — which case? → ABL (mental-condition
   verbs).
6. "a girl *with big eyes*" — which case? → INSTR qualitative.
7. "Aram is *in Yerevan*" (colloquial speech) — which case? → bare
   NOM with place name + copula; LOC in writing.
8. "He told the children a story" vs "he learned it from the
   children" — DAT addressee vs ABL source.
9. "*Whose* book is this?" and "*to whom* did you give it?" — same
   word ո՞ւմ, GEN vs DAT function.
10. "We covered 20 km *in an hour*" — which case for "hour"? → LOC
    temporal.

## Gaps

- Question words are mostly *not* in Dum-Tragut. Attested links
  (all listed with fragments in the body tables above): local NOM
  ո՞ւր / "where (to)?" (dumtragut p99, p400), LOC որտե՞ղ (dumtragut
  p400), local ABL որտեղի՞ց (dumtragut p400), INSTR path որի՞
  վրայով / որի՞ մոտով (dumtragut p400), the temporal question set
  (dumtragut p402, case mapping p403), the causal ABL set
  (dumtragut p405). Everything marked *(prior)* is constructed
  here — project knowledge, not citation.
- parnasyan p120–124 (question-pronoun declension, Russian glosses)
  is OCR-garbled; the declined forms were read through noise and
  should be re-checked against the page bitmap before promotion to
  a topic file.
- The distributive is *not* an ablative function in Dum-Tragut
  (suffix -ական, dumtragut p138) — contrary to what one might
  import from Russian по-distributives.
- Corpus quotes preserve source/OCR typos verbatim; each carries an
  inline *(sic — read …)* correction. The corrections themselves
  are editorial (prior), chosen as the obvious intended form.
- The endings table covers only the productive -ի declension
  (sakayan p102 sample nouns); irregular stems the examples
  silently use (գարուն → Գարնանը, առավոտ → Առավոտվանից, տեր →
  տիրոջից) are not yet systematized here — candidate for a
  follow-up on declension classes (dumtragut pp. 85–97).

## Appendix: method

Six parallel mining agents over the four corpus JSONLs, one per
case group plus one for question-word paradigms; every
backtick-quoted Armenian fragment is verbatim corpus bytes; page
numbers are the JSONL `page` field. Post-assembly audit re-checks
every fragment@cite pair with the same whitespace-squashed NFC
matching the repo's `armenian_self_check` hook uses. Critic pass
per `CLAUDE.md` § "Critic-agent pattern": one structural
adversarial agent (re-read every cited page), one editorial agent
(learner persona, L1 Russian).

# Yerevan district-name register typology

Status: **research note** — captured from operator observation;
not promoted to `topics/` because no four-book corpus citations
exist for the district nicknames themselves. Surface evidence:
the wall photo `photo_5199905489704129439_y.jpg` and the walk
`walks/2026-05-14-armenian-grammar-on-russian-wall.md`. Promote
to `topics/lexicon/` when corroborating corpus data accumulates
(social-media corpus, contemporary news, published register
lexicon, etc.).

Yerevan-vernacular reference to city districts draws on **three
distinct naming sources**, each carrying its own register and
typically its own script convention. This typology is captured from
the workspace-operator's observation; corpus corroboration is the
main gap (see frontmatter).

## The three sources

### 1. Current administrative / official street names

The current city-issued toponym. Used in transit, postal addresses,
maps, news. Examples (Armenian-script in official use; Cyrillic /
Latin-transliterated forms appear in Russian-language contexts):

| Armenian | English / common transliteration | source |
|---|---|---|
| `Նար-Դոս փողոց` | Nar-Dos Street | named after Armenian writer Մ. Հովհաննիսյան, pen name Նար-Դոս (1867–1933) |
| `Աբովյան փողոց` | Abovyan Street | after writer Խաչատուր Աբովյան |
| `Մաշտոցի պողոտա` | Mashtots Avenue | after Մեսրոպ Մաշտոց |

These names are referentially current and politically uncontested
(post-Soviet renaming has stabilised). Used as the **outer-register**
identifier — a stranger or formal speaker uses this form.

### 2. Inherited administrative names, often translated

Older administrative or quasi-administrative names — typically from
the Soviet-era administrative layer — that persist in colloquial use.
Often **translated rather than transliterated** when crossing scripts.

| Armenian / Russian | English | comment |
|---|---|---|
| `Մոնումենտ` / *Monument* | "Monument" | the Victory monument area, north-central. Russian *Монумент*, Armenian formal `Հաղթանակ` "Victory", colloquial use `Մոնումենտ` |

These names sit semantically and historically *between* the official
current name and the pure-nickname layer. Used in colloquial speech
without sounding "edgy."

### 3. Transformed nicknames

Pure colloquial nicknames, often:
- Derived from older street names that have since been renamed
  (e.g. `Krivo` — reportedly from a Russian-era street name in the
  Nar-Dos area).
- Or formed by transformation / abbreviation / metonymy of some
  feature of the district.
- Often written in **Cyrillic on walls** even when speakers
  otherwise use Armenian / Latin, because the script choice itself
  signals register (in-group, gangster-tag, etc.).

Examples:

| Nickname | colloquial register | comment |
|---|---|---|
| `Կարճ Նար-Դոս` / *Кривой Нар-Дос* / `KRIVO NAR-DOS` | tag / gangster-territorial | the wall datum (`photo_5199905489704129439_y.jpg`) — the bent stretch of Nar-Dos, or a sub-district adjacent to it. |
| `Силачи` | colloquial | operator-sourced; **below the web horizon**. A web search returns only a "Silachi Hotel" listing in Yerevan, no etymology or district article. Suggests a deeper-oral nickname, less institutionally indexed than `Բանգլադեշ` or `Հնդկաստան`. |
| `Բանգլադեշ` / *Bangladesh* | colloquial (well-known) | sub-area of Malatia-Sebastia district. Etymology corroborated: Ajam Media Collective (2014) — "because it's hot, poor, far away, and nobody knows much about it." Soviet-era pejorative, where Asian-country names were used as poverty/remoteness metaphors. |
| `Հնդկաստան` / *Hindkastan* | colloquial | "India" — named for the Hayreniq cinema, which programmed Indian films in the 1970s. Metro exits sometimes greeted by Bollywood music. Same era / typology as `Բանգլադեշ`. |
| `Կոնդ` / *Kond* | quasi-administrative + colloquial | Yerevan's oldest quarter, central, hilltop. Now official-ish (mapped, named in tourism). Persian-rule historical name: *Tapabashi* (Turkish *tepe-baş* "hill-top"). Category-1.5: started as colloquial topography descriptor, now stabilised in the administrative layer. |

The wall photo's `KRIVO NAR-DOS` is the **canonical disambiguation
move**: pin a specific sub-zone by stacking the colloquial-nickname
modifier (`Krivo`) onto the current-street official toponym
(`Nar-Dos`). Like English "the Bedford-Stuy part of Brooklyn."

## Script conventions

A district can be written in three scripts depending on register and
context:

| script | typical register |
|---|---|
| Armenian (`Կարճ Նար-Դոս`, `Մոնումենտ`) | newspaper, official, neutral colloquial |
| Cyrillic (`Кривой Нар-Дос`, `Силачи`, `Монумент`) | older inherited register; intra-Russian-speaking context; gangster-tag / wall-graffiti |
| Latin (`KRIVO NAR-DOS`, `BRATVA`) | younger / internet-influenced wall tag; intentional script-mixing |

The wall datum mixes all three positionings within a single tag —
Cyrillic `ВСЕМ ПРОТИВ`, Latin-transliterated Russian `BRATVA` /
`KRIVO NAR-DOS`. Script choice within a single piece can index
internal genre boundaries (slogan vs. tagline vs. signoff).

## Web corroboration

A focused web pass (2026-05-14) corroborates the three-source
typology with external sources for the well-known examples and
confirms the "below the web horizon" status of the deeper-oral
nicknames:

- **Bangladesh** — [Ajam Media Collective (2014)](https://ajammc.com/2014/06/04/bangladesh-portrait-of-a-yerevan-suburb/)
  documents both the existence and the etymology. The piece also
  notes that "in the relatively closed world of the Soviet Union,
  personal contact with people from India and Bangladesh was
  extremely rare," which makes the country-name metaphor work as a
  remoteness/exoticism cue rather than a literal-comparison.
- **Hindkastan** — same Ajam piece. Cinema-driven naming, not
  poverty-driven (so the country-name-pattern is more
  associative-thematic than uniformly pejorative — `Հնդկաստան`
  doesn't carry the same valence as `Բանգլադեշ`).
- **Kond / Tapabashi** — etymology in both the
  [Wikipedia districts entry](https://en.wikipedia.org/wiki/Districts_of_Yerevan)
  and Yerevan-specific blogs ([Travelers and Dreamers](https://travelersanddreamers.com/kond-yerevan/),
  [We Did It Our Way](https://wediditourway.com/yerevan-oldest-neighborhood-kond/)).
  The fact that Kond has *crossed over* from colloquial to
  quasi-administrative naming makes it a case study for how
  Yerevan toponym categories move over time.
- **Silachi** — confirmed below the web horizon. No district-level
  etymology indexed in Russian-language or English-language
  sources via standard web search. Single related hit: a hotel
  named *Silachi*. The colloquial nickname appears to circulate
  in oral and possibly local-media-only registers — a candidate
  for a more targeted search (Armenian-language sources;
  Russian-language Yerevan blogs; Facebook-group archive of
  Yerevan history pages) before promotion.
- **Krivo (Кривой)** — also below the web horizon. Same status as
  Silachi: operator-sourced, no indexed etymology, but
  surface-attested on the wall datum
  `photo_5199905489704129439_y.jpg`.

A pattern: the country-name-metaphor nicknames (`Բանգլադեշ`,
`Հնդկաստան`) are well-indexed because they're cited in English-
language media coverage. The Russian-origin transformed
nicknames (`Կարճ`, `Силачи`) sit deeper in the oral register and
don't index — which is itself a register fact, not a
documentation gap.

## Open gaps

- No four-book corpus attestation of the district nicknames
  themselves. Corroboration would need a contemporary Yerevan-
  Russian / Yerevan-Armenian corpus (social media, news, oral
  history) or a published register lexicon.
- Etymologies of specific nicknames (`Силачи`, `Krivo`,
  `Monument`, etc.) are operator-sourced, not externally cited.
  `Krivo` is reportedly from an older Russian-era street name in
  the Nar-Dos area; `Monument` derives from the Soviet-era
  administrative naming layer (Armenian counterpart `Հաղթանակ`
  "Victory"); `Силачи` is a transformed older nickname. None
  externally verified in this note.
- Comprehensive list not enumerated. Likely candidates by
  district: `Մոնումենտ` / Monument (north-central, around the
  Victory monument), `Բանգլադեշ` / Bangladesh (south-west
  high-density), `Կոնդ` / Kond (old district), `Կարճ Նար-Դոս` /
  `Krivo Nar-Dos` (the wall datum), `Սիլաչի` / `Силачи`,
  `Մալաթիա` / Malatia. Each merits its own row when corroborating
  evidence surfaces.
- Systematic survey of which scripts attach to which nicknames in
  which contexts — not done. The three-bucket script convention
  above is a working hypothesis from the single wall datum, not a
  surveyed claim.
